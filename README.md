# 落点 AI 官网与案例库

咨询商务风格的企业 AI 转型官网与业务方案库。根路径是服务官网，方案库覆盖 14 个行业与 193 篇参考方案。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 内容边界

- 全部内容标记为 `参考方案`，人物与企业背景为虚构，不是既有客户案例。
- 指标给出测量口径，不宣称已经取得实测收益。
- 公开研究线索保留在内部 `research/` 和 `findings.md`，来源正文、销售话术与客户成果不进入公开数据。
- 当前需求单仅在浏览器本地生成，不上传信息。

## 页面与验证

- 官网：`/`
- 行业体验台：`/demos/`，可直接链接 `#crm`、`#order`、`#reconcile`、`#sales`、`#inquiries`、`#quotes`、`#delivery`、`#costing`
- 案例库：`/cases/`
- 示例详情：`/cases/?case=case-096`
- 收藏：`/cases/?saved=1`
- 筛选与分页写入 URL，详情返回时保留筛选；收藏保存在当前浏览器。
- 每篇详情包含 9 个章节、39 个公开字段；先用情景故事讲清楚问题与解决过程，再展开模块、流程、数据、接入、试点、验收、成本与风险。
- `npm run audit:copy` 检查来源正文泄漏、高相似标题、重复叙述、AI 套话和生成病句。
- `npm run verify:ui` 验证 193 篇详情、搜索/筛选/收藏/分页/返回/下载，以及六档屏幕宽度。
- 验证默认使用本机 Google Chrome，可通过 `CHROME_PATH` 和 `BASE_URL` 覆盖。
- 对生产构建验证：先运行 `npm run preview -- --port 4174`，再运行 `BASE_URL=http://127.0.0.1:4174 npm run verify:ui`。
- 详情页的打印按钮可通过浏览器保存 PDF。

## 行业交互 Demo

首页与案例库导航均有体验台入口。八个工作场景：前三个日常助手共五组行业样例，后五个为增长与经营工作台。

- 微信转 CRM：箱包外贸、机床销售。修改聊天、整理字段、定位原文、编辑并确认；导出可阅读的 TXT 草稿。
- 订单变更检查：服装款色码、电动童车配置。对照原单计算尺码变化，识别电池和充电器标称电压冲突；逐项复核后导出 TXT 变更草稿。
- 单据核对：箱包配件采购。编辑采购、收货、对账数据，识别数量、单价、单号、名称与疑似重复行；记录处理结论，导出带原始依据的 CSV。

新增五个工作台（参考同类产品的业务流程，自行实现界面、代码和虚构行业数据）：

- `#sales` 销售跟进：四个行业商机、负责人筛选、沟通时间线、停滞依据、可编辑沟通草稿及跟进任务。不生成成交概率，不自动发送消息。
- `#inquiries` 询盘转商机：展会、邮件、官网三个固定询盘，产品目录映射、缺失信息清单、同名项目人工查重、分配负责人，保存合并或新建商机的本地处理草稿。不会实际跨页面创建 CRM 记录。
- `#quotes` 报价版本：对比数量、包装、FOB / CIF、运保费；解释口径变化；调整价格生成新版本。以固定样例成本为边界，低于成本禁止保存。
- `#delivery` 订单交付：3,000 个登机箱缺 600 套拉杆；比较等齐料、分批和加急的固定场景，显示预计日期、额外费用和待批准前提，生成本地协调单。不是实时排程优化器。
- `#costing` 成本报价：箱包、童车和机加工三套成本模板；数量、成本、目标毛利与让利可改；工装分摊、毛利公式和货币舍入由确定性规则计算。口径为人民币不含税，未计账期、售后及汇率风险。

新工作台有约 2.9 秒的三阶段处理展示，支持取消和切换终止。所有演示以 2026-09-18 为固定基准日；每次刷新恢复样例。新工作台复核后均可导出中文 TXT，带依据与待确认事项。参考产品为 OpenCoDev 的外贸 CRM、统一询盘、报价版本、交期看板和成本报价方向；没有嵌入第三方 Demo 或调用其接口。

点击导出先打开内容预览，再下载文件；也可直接选中文本复制。修改输入会清除旧结果，修改复核结果会取消已确认状态。刷新页面恢复样例，当前版本不保存到服务器或浏览器持久存储。

CRM 输入使用微信风格的左右气泡、头像和时间展示，展开“修改聊天内容”可编辑原文；点击结果依据会高亮对应聊天气泡。三个场景均有约 3.25 秒的分步流程演示；处理中禁止重复启动，支持取消，修改输入、重置或切换场景会终止旧任务，避免旧结果覆盖新输入。系统减少动态效果设置下关闭旋转动画。

这是一套**本地规则驱动的前端演示**，全部为虚构样例。没有连接模型 API、微信、CRM、ERP，也不具备文件 OCR 能力。提取只支持页面样例句式；复杂、多产品、否定与多次修改等要求必须人工核实。对账按相同编码归组，以分为单位计算金额，疑似重复行保留在合计中并提示，不能把差额当作损失。未来接入模型时，应保留字段来源、人工确认、输入变更失效和规则校验。

`npm run test:demos` 检查输入变化、L / XL 隔离、配置冲突、对账修正、非法输入与 CSV 转义，以及毛利率/加价率区分、让利、货币舍入、数量分摊、报价可比性、缺料数量及加急成本。前端已手动验证桌面与 390px 手机布局、主要复核交互和导出预览。预览浏览器未返回下载完成事件，实际落盘仍需在客户使用的浏览器确认。

## 案例迁移

- `npm run migrate:cases` 从 `research/snapshots/opencodev-solutions-2026-09-14.html` 重新生成案例数据。
- 脚本要求源数据严格等于 14 个行业、83 个细分场景、193 条问题记录；数量变化会直接失败。
- 迁移时排除销售脚本、第三方 Demo、设备类型和 AI 加分话术，并拒绝来源品牌与承诺型数字进入公开数据。
- `research/migration-manifest.json` 保存快照哈希、输入输出数量及排除字段。
- 页面公开身份统一为“参考方案”，不声称为落点 AI 已交付客户案例。

## 上线前必须确认

1. 将工作品牌“落点 AI”替换为正式品牌与公司主体。
2. 接入真实邮箱、企业微信、飞书表单或 CRM。
3. 根据实际交付成本确定报价或报价规则。
4. 取得首批客户授权后，再增加可核验的真实案例。
